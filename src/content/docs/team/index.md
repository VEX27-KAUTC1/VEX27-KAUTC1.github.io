Member profiles and dated journals live here. No roster has been supplied, so there are no invented profiles.

## Add a member

1. Copy `templates/member-profile.md` to `src/content/docs/team/members/<github-handle>.md`.
2. Fill in the real name, responsibilities, approved robot assignments, and links.
3. Submit a pull request for review.

Daily reports go in `src/content/docs/team/journal/YYYY-MM-DD-<github-handle>-<topic>.md`. The [daily report template](../resources/templates/) explains each field. The homepage automatically shows recent reports after merge.
