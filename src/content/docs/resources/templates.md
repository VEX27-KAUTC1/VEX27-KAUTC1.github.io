# Document templates

Copy the matching file from the repository `templates/` directory:

- `daily-report.md` — dated member journal
- `member-profile.md` — profile and contributions
- `research.md` — alternatives and conclusion
- `subsystem.md` — calculations, CAD, code, verification
- `design-decision.md` — durable decision record
- `test-report.md` — test method and measured evidence
- `meeting-notes.md` — meeting outcomes

See the repository's `CONTRIBUTING.md` after the verified organization link is configured.
