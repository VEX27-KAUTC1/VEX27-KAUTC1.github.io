# VEX27 Engineering Hub

[Open the website](https://vex27-kautc1.github.io/) - documentation for our two robots, team work, and research.

## Add your work

| Task | Copy this template | Save under `src/content/docs/` |
| --- | --- | --- |
| Member profile | [Member profile](templates/member-profile.md) | `team/members/` |
| Daily report | [Daily report](templates/daily-report.md) | `team/journal/` |
| Research | [Research](templates/research.md) | `research/` |

Open a template and click **Raw** to copy it. Use **Add file > Create new file** on GitHub, paste the content, and open a pull request. After review, the website updates automatically.

Name daily reports `YYYY-MM-DD-your-name-topic.md`. Document robot subsystems under `robots/robot-1/` or `robots/robot-2/`.

Only share information approved for the public site. Keep private strategy and large CAD files in restricted storage. See [CONTRIBUTING.md](CONTRIBUTING.md) for details.
